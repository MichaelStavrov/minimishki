## Резервное копирование

Путь: Рег.облако → Виртуальные серверы → Vanilla Osmium → Резервные копии.
Копирование включено; панель сообщает ежедневное создание копий.
Политика проверена по скриншоту и оставлена без изменений:

| Политика хранения | Количество |
|---|---|
| Ежедневные | 0 |
| Еженедельные | 2 |
| Ежемесячные | 0 |
| Годовые | 0 |
| Последние сохранённые | 2 |

Ноль в политике ежедневного хранения не отключает ежедневное создание.
Одна версия может учитываться несколькими политиками; удаление старых версий
не обязательно происходит одновременно. Политика не означает фиксированные
четыре отдельные копии навсегда.

Подтверждённые копии по последнему скриншоту:

- ручная **30.10.2026 в 16:08**, создана после проверки рабочего сайта;
- по расписанию 30.10 в 09:27, 29.10 в 09:26 и 28.10 в 09:26.

Всего показано 4 сохранённые копии, общий объём 0,7 ГБ; сводка последней
операции — 30.10 в 16:09. После ручного запуска кнопки временно блокировались,
затем стали доступны, новая копия появилась в списке. Восстановление из этой
копии отдельно не тестировалось.

На форме услуги указана цена хранения 0,0072 ₽/ГБ·час (до 5,26 ₽/ГБ·месяц).
Оценка при неизменном объёме 0,7 ГБ — около 3,68 ₽/месяц; фактический платёж
зависит от объёма и времени хранения. Полный диск 30 ГБ не равен автоматически
объёму хранимых копий.

## Оставшиеся вопросы и продолжение

Обязательных незавершённых действий по восстановлению сайта нет.
По запросу пользователя можно отдельно проверить:

1. Баланс, уведомления и автопополнение Рег.облака для предотвращения неоплаты.
2. Доставку заявок через MAX/SMTP после восстановления, если нужна проверка
   всей цепочки, а не только страниц сайта.
3. Использование почты/FTP, записи которых остаются на старом IP.
4. Отдельную резервную копию вне аккаунта провайдера: пока не настроена.

Не обещать сохранность копий при неоплате/удалении аккаунта: условия нужно
проверять отдельно. Пароли, токены и приватные ключи не запрашивать в чат.

Справка провайдера:
<https://reg.cloud/support/cloud/oblachnyye-servery/rabota-s-serverom/rezervnoe-kopirovanie-oblachnyh-serverov>.
Текст страницы не извлёкся веб-инструментом; сведения о настройках и цене выше
подтверждены скриншотами кабинета, а не полным прочтением статьи.
