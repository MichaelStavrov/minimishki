## Быстрый старт новой сессии

1. Прочитать [`06-progress.md`](./06-progress.md) → узнать текущий шаг.
2. Прочитать [`00-process.md`](./00-process.md) → вспомнить правила выдачи кода.
3. Найти описание шага в [`03-steps.md`](./03-steps.md).
4. Если пишется код приложения — свериться с [`07-conventions.md`](./07-conventions.md).
5. Выдать код, дождаться подтверждения, обновить [`06-progress.md`](./06-progress.md).
